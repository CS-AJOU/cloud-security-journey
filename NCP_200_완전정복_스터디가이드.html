국내 서비스로 한국 대상으로 대용량 파일 다운로드를 하고자 한다. 이때 현재 사용 가능한 적절한 상품은?

💡 국내=CDN+, 해외=GCDN. GRM은 DNS 라우팅용.
11

1) GCDN
2) Global Route Manager
3) GIS
4) Load Balancer
✓ 정답: 2번

Global Route Manager(GRM)는 DNS 기반 로드 밸런싱 서비스로, 접속자 IP의 지리적 위치(Geolocation)에 따라 최적의 리전 서버로 라우팅해줘.

💡 GRM = DNS 기반 지역별 라우팅. Geolocation 알고리즘 지원.
12
다음의 설명을 지칭하는 용어는? '서비스로의 인프라를 의미하며 일반적으로 Computing, Networking, Storage 등의 IT 리소스를 서비스 형태로 사용하는 클라우드 컴퓨팅의 한 종류'
▾
1) PaaS
2) IaaS
3) SaaS
4) FaaS
✓ 정답: 2번

💡 IaaS(인프라) → PaaS(플랫폼) → SaaS(SW) → FaaS(함수) 순으로 추상화 수준↑

🖥️ SECTION 02

Compute / Server

서버 타입, 스펙, GPU, 베어메탈, VDS, Micro, Live Migration

기출 문제 30문항
1
VPC환경/Classic 2세대 서버의 Standard 서버 스펙 중 생성 가능한 서버 스펙은 무엇인가요?
▾
1) vCPU 2개, RAM 8GB
2) vCPU 2개, RAM 4GB
3) vCPU 2개, RAM 16GB
4) vCPU 4개, RAM 4GB
✓ 정답: 1번

Standard 서버는 vCPU:RAM = 1:4 비율. 2vCPU면 8GB RAM이 정답.

💡 Standard 비율 1:4 / High-CPU 1:2 / High-Memory 1:8
2
VPC/Classic 2세대 서버의 High Memory 서버 스펙 중 생성 가능한 서버 스펙은?
▾
1) vCPU 4개, RAM 8GB
2) vCPU 8개, RAM 8GB
3) vCPU 2개, RAM 8GB
4) vCPU 16개, RAM 128GB
✓ 정답: 4번

High Memory는 vCPU:RAM = 1:8 비율. 16vCPU × 8 = 128GB RAM.

💡 High-Memory = CPU × 8 = RAM 용량.
3
VPC 환경의 Standard 서버 타입 중 지원하지 않는 서버 스펙은?
▾
1) 2vCPU 8G RAM
2) 4vCPU 16G RAM
3) 8vCPU 32G RAM
4) 12vCPU 64G RAM
✓ 정답: 4번

Standard는 1:4 비율이라 12vCPU면 48GB RAM이어야 하지만, 실제로는 12vCPU 스펙 자체가 없어. Standard는 2, 4, 8, 16, 32 vCPU 단위로 제공.

💡 vCPU는 2의 배수(2, 4, 8, 16, 32...)로만 제공. 12는 없음.
4
네이버 클라우드 플랫폼의 GPU 서버에 대한 설명으로 옳은 것을 고르시오.
▾
1) 서버 한 대에 최대 12장의 GPU 카드를 작성할 수 있다.
2) GPU Core 단위로 할당 가능하다.
3) PCI Pass Through 방식으로 제공한다.
4) Tesla P100을 제공한다
✓ 정답: 3번

NCP GPU 서버는 PCI Pass Through 방식으로 GPU 카드를 통째로 VM에 할당해. 최대 8장까지 가능(12장 X), Core 단위 할당 불가, P40/T4/V100 제공(P100 X).

💡 PCI Pass Through = 가상화 오버헤드 없이 GPU 성능 그대로 활용.
5
네이버 클라우드 플랫폼 VPC 환경에서 제공되는 GPU 서버의 특징으로 틀린 것은?
▾
1) NVIDIA T4, V100 이용이 가능하다.
2) 서버 1대당 꽂을 수 있는 T4의 최대 개수는 2개이다.
3) 서버 1대당 꽂을 수 있는 V100의 최대 개수는 4개이다.
4) Grid 기술을 사용할 수 있다.
✓ 정답: 4번

NCP GPU 서버는 PCI Pass Through 방식이라 NVIDIA Grid(GPU 분할 공유) 기술은 지원 안 해. Grid는 하나의 GPU를 여러 VM이 나눠쓰는 기술이야.

💡 PCI Pass Through vs Grid는 서로 배타적.
6
베어메탈 서버에 대한 설명 중 잘못된 것을 고르시오.
▾
1) 디스크는 RAID 1+0, RAID 5 중 선택할 수 있다.
2) 내 서버 이미지를 사용할 수 없다
3) Ubuntu OS는 제공하고 있지 않다.
4) Windows 2012 OS가 제공되고 있다.
✓ 정답: 4번

베어메탈은 CentOS, Ubuntu, Oracle Linux 등을 지원하지만 오래된 Windows 2012는 제공하지 않아. 최신 Windows 버전만 지원.

💡 Windows 2012는 지원 종료. 최신 서버 OS만 지원.
7
베어메탈 서버에 대한 설명 중 잘못된 것을 고르시오
▾

서버가 운영 중이어도 OS 내부에서 마운트 해제된 상태라면 detach 가능. 사용 중인 볼륨을 강제 detach하면 데이터 손상 우려.

💡 detach 조건: OS 내부 unmount 필수.

NAS 볼륨에 대한 설명으로 적합한 것은?
▾
1) NAS 볼륨을 생성하면 NAS 전용 웹페이지 URL이 생성되며, 로그인할 수 있는 ID/PW가 생성된다.
2) NAS 스냅샷 이미지는 용량, 기간 제한 없이 생성 가능하다.
3) VM에 NAS를 마운트하기 위해서는 Private Subnet 생성 후 해당 VM에 추가 NIC를 등록해야 한다.
4) NAS 스냅샷은 NAS 볼륨 내 설정한 용량(%)만큼 생성되며, 초과 시 오래된 것부터 삭제처리된다.
✓ 정답: 4번

NAS 스냅샷은 볼륨 용량의 일정 % 이내에서 관리되고, 초과되면 오래된 스냅샷부터 자동 삭제돼.

💡 NAS 스냅샷 = 볼륨 % 할당. 초과 시 FIFO 삭제.

💡 라이프사이클 = Object → Archive 자동 이관. 비용 절감.

💡 RAID 1 = 미러링(50% 손실). 읽기↑, 쓰기 동일.

💡 RAID 0 = 성능↑ 안정성↓. 백업 없음.

3) 저장공간의 손실이 50%이다.
4) 단순 볼륨에 비해 읽기, 쓰기 속도가 뛰어나다.

💡 RAID 1+0 최소 = 4개 디스크.
